# lab3-task3: Дроби с комплексными коэффициентами

## Условие

Создать массив дробей m/n с комплексными m и n; каждый элемент с чётным индексом увеличить на следующий.

## Решение

Complex и ComplexFraction неизменяемы. Сложение дробей: (a/b)+(c/d)=(ad+cb)/(bd). Отдельный сервис изменяет массив. Последний непарный элемент не изменяется.

## Запуск из корня JavaLabs

```sh
mvn -q -pl lab3-task3 compile exec:java
```

## Пример ввода

```text
3
1 1 2 0
1 -1 2 0
5 0 1 0
```

## Ожидаемый результат

Дроби 0 и 1 имеют значения (0.5+0.5i) и (0.5−0.5i). После преобразования элемент 0 равен 1+0i; элемент 1 прежний; элемент 2 равен 5+0i.
