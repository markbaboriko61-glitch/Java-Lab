# lab3-task17: Семь алгоритмов сортировки

## Условие

Класс массива с сортировками: пузырьковой, шейкерной, выбором, адресной, вставками, бинарного слияния и Шелла.

## Решение

Каждый алгоритм получает независимую копию исходного массива. Адрес вычисляется в long, что предотвращает переполнение при разности крайних значений int. Все сортировки по возрастанию.

## Запуск из корня JavaLabs

```sh
mvn -q -pl lab3-task17 compile exec:java
```

## Пример ввода

```text
5 -1 5 0 -10
```

## Ожидаемый результат

Для каждого алгоритма: [-10, -1, 0, 5, 5].

## Тесты

```sh
mvn -pl lab3-task17 verify
```
