# lab2-task3: Самые длинные монотонные участки строк

## Условие

Найти максимальный непрерывный возрастающий/убывающий участок каждой строки, отсортировать строки по его длине и построить зубчатый массив из исходных строк.

## Решение

Один проход по строке хранит начало текущего и лучшего участка. При равенстве длин сохраняется первый участок. Сортировка строк стабильная, исходная матрица не изменяется.

## Запуск из корня JavaLabs

```sh
mvn -q -pl lab2-task3 compile exec:java
```

## Пример ввода

```text
3
1
1 2 3
4 4 4
2 3 0
1
1
```

## Ожидаемый результат

Длины: 3, 1, 2. Порядок строк: [4,4,4], [2,3,0], [1,2,3]. Зубчатый массив: [1,2,3], [4], [2,3].

## Тесты

```sh
mvn -pl lab2-task3 verify
```

## Две реализации

Одно и то же задание решено двумя способами: обычным и через Stream API. При запуске Main ввод матрицы выполняется один раз, затем выводятся оба результата. Исходная матрица не изменяется.

- `MatrixSequences` — обычные циклы и сортировка строк.
- `MatrixSequencesStream` — границы монотонных участков через IntStream, выбор первого максимального участка через reduce, сортировка и построение зубчатого массива через Stream.

Дополнительные тесты сравнивают обе версии на 200 случайных наборах данных и проверяют граничные случаи.
