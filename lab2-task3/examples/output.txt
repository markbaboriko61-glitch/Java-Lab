Размерность квадратной матрицы n: Ввод: 1 — вручную, 2 — случайно: a[0][0]: a[0][1]: a[0][2]: a[1][0]: a[1][1]: a[1][2]: a[2][0]: a[2][1]: a[2][2]: Последовательность: 1 — возрастающая, 2 — убывающая: Порядок длин: 1 — по возрастанию, 2 — по убыванию: Исходная матрица:
[1, 2, 3]
[4, 4, 4]
[2, 3, 0]
Обычная реализация:
Строка 1: длина 3
Строка 2: длина 1
Строка 3: длина 2
Упорядоченная матрица:
[4, 4, 4]
[2, 3, 0]
[1, 2, 3]
Зубчатый массив из строк ИСХОДНОЙ матрицы:
[1, 2, 3]
[4]
[2, 3]
Реализация через Stream API:
Строка 1: длина 3
Строка 2: длина 1
Строка 3: длина 2
Упорядоченная матрица (Stream API):
[4, 4, 4]
[2, 3, 0]
[1, 2, 3]
Зубчатый массив из строк ИСХОДНОЙ матрицы (Stream API):
[1, 2, 3]
[4]
[2, 3]
