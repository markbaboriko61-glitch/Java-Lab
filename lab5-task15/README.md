# lab5-task15: Диск, каталоги и записи

## Условие

Класс BlueRayDisc с внутренними классами, хранящими каталоги, подкаталоги и записи; анонимный класс.

## Решение

Directory хранит подкаталоги и записи, Recording — имя, размер и длительность. Вложенные каталоги связаны родителями. Общая вместимость проверяется перед добавлением записи. Анонимный Comparator сортирует копию списка записей по длительности.

## Запуск из корня JavaLabs

```sh
mvn -q -pl lab5-task15 compile exec:java
```
