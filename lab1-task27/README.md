# lab1-task27: Числа с цифрами 0, 2, 3, 7 по одному разу

## Условие

Вывести p-значные натуральные числа, содержащие цифры 0, 2, 3, 7 каждую ровно один раз.

## Решение

Для каждого числа подсчитывается количество цифр и массив частот 0–9. Проверяются длина p и четыре частоты, равные 1.

## Запуск из корня JavaLabs

```sh
mvn -q -pl lab1-task27 compile exec:java
```

## Пример ввода

```text
6
4
2037 2307 1237 20377 7302 203
```

## Ожидаемый результат

Подходящие числа: [2037, 2307, 7302], количество 3.

## Тесты

```sh
mvn -pl lab1-task27 verify
```
