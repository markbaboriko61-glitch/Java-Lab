# lab1-task15: Максимальная цифра и её частота

## Условие

Для каждого натурального числа найти наибольшую цифру и количество её вхождений.

## Решение

Цифры извлекаются операциями % 10 и / 10. При новом максимуме счётчик сбрасывается в 1; при повторении текущего максимума увеличивается.

## Запуск из корня JavaLabs

```sh
mvn -q -pl lab1-task15 compile exec:java
```

## Пример ввода

```text
4
90919 1000 7777 5
```

## Ожидаемый результат

90919: цифра 9, 3 раза. 1000: цифра 1, 1 раз. 7777: цифра 7, 4 раза.
