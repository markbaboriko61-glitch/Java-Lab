# lab5-task3: Счёт и история операций

## Условие

Класс Account с внутренним классом для поступлений, снятий и платежей. Продемонстрировать анонимный класс.

## Решение

Account.Operation — нестатический внутренний класс с типом, суммой, временем и остатком. История выдаётся только для чтения. Анонимный Comparator сортирует копию истории по убыванию суммы.

## Запуск из корня JavaLabs

```sh
mvn -q -pl lab5-task3 compile exec:java
```

## Ожидаемый результат

10000.00 − 1500.00 − 2500.50 = 5999.50. Снятие 99999 отклоняется и не изменяет историю.
