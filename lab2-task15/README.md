# lab2-task15: Результаты сессии

## Условие

Первый столбец — уникальный шестизначный номер зачётки, остальные — оценки. Отчислить задолженников и отсортировать оставшихся по среднему баллу.

## Решение

Фильтрация удаляет строки с оценкой 2. Для оставшихся вычисляется средний балл без номера зачётки. Comparator сортирует по убыванию среднего.

## Запуск из корня JavaLabs

```sh
mvn -q -pl lab2-task15 compile exec:java
```

## Пример ввода

```text
3
1
100001 3 4
100002 5 2
100003 5 5
```

## Ожидаемый результат

Отчислен 100002. Оставшиеся: 100003 со средним 5.00, затем 100001 со средним 3.50.

## Тесты

```sh
mvn -pl lab2-task15 verify
```

## Две реализации

Одно и то же задание решено двумя способами: обычным и через Stream API. При запуске Main ввод матрицы выполняется один раз, затем выводятся оба результата. Исходная матрица не изменяется.

- `SessionResults` — обычные циклы, ArrayList и сортировка Comparator.
- `SessionResultsStream` — проверка данных, поиск долгов, вычисление среднего, фильтрация и сортировка через Stream API.

Дополнительные тесты сравнивают обе версии на 200 случайных наборах данных и проверяют граничные случаи.
