# lab3-task15: Множество символов

## Условие

Реализовать принадлежность, объединение, пересечение, разность, методы арифметических операций, присваивание и индексирование; отдельный класс вычисляет симметрическую разность для пар объектов.

## Решение

TreeSet хранит уникальные кодовые точки Unicode. Симметрическая разность: (A\B) ∪ (B\A). Присваивание копирует содержимое. Все пары берутся из массива множеств.

## Запуск из корня JavaLabs

```sh
mvn -q -pl lab3-task15 compile exec:java
```

## Пример ввода

```text
2
abc
bcd
a
```

## Ожидаемый результат

Объединение {a,b,c,d}, пересечение {b,c}, A−B={a}, симметрическая разность {a,d}.
