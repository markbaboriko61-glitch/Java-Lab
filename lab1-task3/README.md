# lab1-task3: Разложение на простые множители

## Условие

Для каждого натурального числа последовательности вывести его простые множители.

## Решение

Сначала извлекаются двойки. Затем перебираются нечётные делители, пока d <= n / d. Остаток больше 1 — простой множитель. Для 1 выводится отдельное сообщение.

## Запуск из корня JavaLabs

```sh
mvn -q -pl lab1-task3 compile exec:java
```

## Пример ввода

```text
5
1 2 13 360 9409
```

## Ожидаемый результат

Для 360: 2 * 2 * 2 * 3 * 3 * 5. Для 9409: 97 * 97.

## Тесты

```sh
mvn -pl lab1-task3 verify
```
