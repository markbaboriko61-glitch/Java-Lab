# Баборико Марк Денисович 2 курс 6 группа

## Лабораторная работа 2

Задания: 15, 3. Java 17+, Maven, JUnit 5.

Каждое задание — отдельный Maven-модуль. Код и тесты не содержат комментариев или Javadoc.

## Проверка

```sh
mvn clean verify
```

## Запуск

```sh
mvn -q -pl lab2-task15 compile exec:java
```

```sh
mvn -q -pl lab2-task3 compile exec:java
```

Условия, пояснения и примеры ввода/вывода — в папках заданий. Команды выполняются из корня ветки.


## Дополнительное требование: Stream API

Для обоих заданий (№3 и №15) есть обычная и отдельная Stream API реализация. Main автоматически выводит результаты обеих версий на одной введённой матрице.
