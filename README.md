# Баборико Марк Денисович 2 курс 6 группа

## Лабораторная работа 4

Задания: 3. Java 17+, Maven, JUnit 5.

Каждое задание — отдельный Maven-модуль. Код и тесты не содержат комментариев или Javadoc.

## Проверка

```sh
mvn clean verify
```

## Запуск

```sh
mvn -q -pl lab4-task3 compile exec:java
```

Условия, пояснения и примеры ввода/вывода — в папках заданий. Команды выполняются из корня ветки.

Приборы читаются из `lab4-task3/src/main/resources/appliances.txt`. Используются Factory Method, Creator и Log4j2 с тремя файлами логов и gzip-архивированием. `mvn verify` требует 100% покрытия строк и ветвей.
